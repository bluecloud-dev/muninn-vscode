# Working on Muninn

Use the same [contributor documentation](docs/README.md) with any editor or AI development environment:

- Start with [setup](docs/GETTING_STARTED.md#development-setup) and [development rules](docs/DEVELOPMENT.md).
- Read [architecture](docs/ARCHITECTURE.md) before changing system boundaries.
- For editor changes, follow the [source fidelity contract](docs/ROUNDTRIP_CONTRACT.md) and [testing guide](docs/TESTING.md).
- Use the [roadmap](docs/ROADMAP.md) for direction and [live issues](https://github.com/bluecloud-dev/muninn-vscode/issues) for task status.

Keep shared guidance in `docs/` and tool-specific configuration local; see [tool choice](docs/DEVELOPMENT.md#editor-and-ai-tool-choice). No particular assistant, plugin, MCP server, or skill is required. Verify behavior in current source and tests before relying on old plans.
